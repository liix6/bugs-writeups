## 📄 Writeup Structure

Each writeup follows a consistent, professional format:

- **Summary** — brief overview of the vulnerability
- **Vulnerability Details** — technical root cause
- **Steps to Reproduce** — reproduction steps
- **Proof of Concept (PoC)** — evidence of exploitation
- **Impact** — business/security impact
- **Root Cause** — underlying flaw in logic or implementation
- **Remediation** — suggested fix
